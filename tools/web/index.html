Working with assets

save = publish

Every asset is code. The Foundry watches assets/. Saving a file repaints the gallery in about a second — no upload, no build step, no image files.

Add an asset

  1. Create a file in assets/<category>/<key>.js.
  2. Export a default object with key, name, category, blurb, what, footprint, height, tags and draw(g).
  3. Draw with the primitives below. Keep the whole object inside the declared footprint.
  4. Save. The gallery updates, the inspector refreshes in place, and validation runs automatically.

Primitives

g.boxAxis-aligned volume. The workhorse: walls, crates, chassis.
g.roofPitched roof, ridge on x or y, with gable ends.
g.cylSilos, tanks, bales, wheels. axis: 'z' | 'x' | 'y', plus r2 for a cone.
g.circleCamera-facing circle. Canopies, berries, lamp glow.
g.decalFlat screen-space polygon at a world anchor. Signs, blades, flags.
PartsShared tree, wheel, window and door helpers live in assets/lib/parts.js.

The bar

Readable at 32 px. Three to six shapes. Four colours plus the shared shadow. Fixed upper-left light, no outlines, no gradients, no text inside the art. If a detail vanishes at thumbnail size, delete it.

Working live

Keep this tab open while we work. New assets appear with a toast and a dot; edits update the open inspector without losing the current orbit. Broken files become a single error card and never take the library down. Turn on Follow edits in the rail to open new assets automatically.
